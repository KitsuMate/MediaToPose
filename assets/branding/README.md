# Media to Pose icon

`media-to-pose-icon-source.png` is the generated high-resolution master for
the extension icon. The publish-ready 256 by 256 export is
`/docs/media/icon.png`.

The icon was generated with the built-in OpenAI image generation tool using
`/docs/media/banner.png` as a palette and style reference. The selected
direction shows a white media frame beside a warm red-orange pose armature on
a dark graphite rounded tile. It contains no text.

The final export was resized with Pillow using Lanczos resampling, then refined
in GIMP. Its SHA-256 is
`75D7F39559EFDEFE3800781CFB583B6434158A23332EDCE77E19A834F050C441`.
